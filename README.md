# Ground Booking System - Frontend

A modern sports ground booking frontend built using React.js.

Users can:
- Register/Login
- Browse available grounds
- Book grounds
- View booking history
- Make payments
- Contact admin

Admins can:
- Manage grounds
- Manage users
- Manage bookings
- Manage payments
- View contact messages

---

## 🚀 Tech Stack

- React.js
- React Router DOM
- Axios
- Bootstrap 5
- CSS

---

## 📂 Features

### User Features
- User Registration & Login
- Protected Routes
- Browse Grounds
- Ground Details Page
- Real-time Booking
- Booking History
- Payment History
- Contact Support

### Admin Features
- Admin Dashboard
- Add/Edit/Delete Grounds
- Manage Users
- Manage Bookings
- Refund Management
- Contact Message Management
